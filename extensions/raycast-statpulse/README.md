# StatPulse Raycast Extension

Control StatPulse directly from Raycast using its built-in CLI (`--json`) and `statpulse://` deep links.

## Import into Raycast
1. Open Raycast → **Import Extension**.
2. Select `extensions/raycast-statpulse`.
3. Run `npm install && npm run dev` inside `extensions/raycast-statpulse`.
